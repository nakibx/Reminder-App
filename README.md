# Reminder-App

A modern and user-friendly Reminder & Alarm App interface designed to help users manage daily tasks, organize schedules, and never miss important events.

Figma Link: https://www.figma.com/design/YJjWtL0NTOtUh36XUDmsHM/Reminder-App?node-id=0-1&t=ArPTvr7uPGOgCtQy-1
## 📱 Project Overview

This project focuses on creating a clean, minimal, and intuitive reminder experience with both **Light Mode and Dark Mode**. Users can create reminders, customize repeat schedules, manage expiration settings, and receive reminder notifications through a simple interface.

## ✨ Key Features

- **Reminder List:** View and manage all saved reminders.
- **Reminder History:** Keep track of previous reminders.
- **Create New Reminder:** Add a title, notes, date, and time.
- **Repeat Options:** Set reminders to repeat daily, weekly, monthly, yearly, or with a custom schedule.
- **Skip Days:** Select specific days to skip.
- **Expiration Settings:** Set an expiration date and time for reminders.
- **Alarm Notification:** View reminder alerts with a dedicated notification screen.
- **Light & Dark Mode:** Switch between two visually balanced themes.
- **Simple Navigation:** Enjoy an organized and easy-to-use interface.
